# 안녕하세요, 프론트엔드 개발자 김우중입니다 👋

Vue와 React를 기반으로 금융·공공·커머스 분야의 사용자 웹과 관리자 시스템을 개발해 왔습니다.

프로젝트에 따라 **프론트엔드 설계와 개발을 단독으로 담당**하거나, **프론트엔드 리드**로서 개발 일정 관리, 업무 배분, 기술적 의사결정을 맡았습니다. 신규 서비스 구축부터 기존 서비스의 유지보수와 개선까지 경험했습니다.
